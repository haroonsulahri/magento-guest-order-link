# Brand Assets

The canonical extension artwork is stored in `docs/images`:

- `link-guest-order-to-customer-icon.svg` is the scalable source for extension listings.
- `link-guest-order-to-customer-icon.png` is the 512 x 512 transparent fallback.
- `link-guest-order-to-customer-banner.png` is the 1600 x 640 repository banner.
- `haroone-logo-badge.svg` and `haroone-logo-badge.png` are the approved rounded Haroone badge sources.

The extension icon uses deep-navy monoline order and customer shapes, a blue-to-cyan link, and a lower assignment curve. It intentionally contains no Haroone logo or wordmark. The Haroone logo is reserved for the banner.

The canonical banner displays **LINK GUEST ORDER TO CUSTOMER**, the Haroone mark and the order-to-customer visual. Its repository copy is exactly 1600 x 640 pixels.

Keep the original proportions. Do not add store, customer, order or environment-specific information to public artwork.
